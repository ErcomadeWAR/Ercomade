About the Game

ERCOMADE AIRO WAR is a 2D war game about the conflict between Ukraine and Russia, featuring drones and missiles. Built with Godot Engine 4.7.2. The game includes multiple units — TU-95MS, X-101, GEREN-2 jet drone, Iskander-M, MiG-31K, Flamingo, HIMARS and PVO — along with several game modes and four distinct maps with factories.
